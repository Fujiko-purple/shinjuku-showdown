## 1. 五条悟（五条悟 / ごじょう さとる）

### 1.1 六眼（りくがん）

**原作里具体怎么运作**
- 六眼是**五条家发現的特殊体质，不是生得术式**；是**使用无下限咒术的必要条件**（没有六眼就无法驾驭无下限）。【B】
  - https://dic.pixiv.net/a/%E5%85%AD%E7%9C%BC
- 效果是**对术式与咒力的超精密识别**：能读取对方术式的详细信息、把握咒力流向，从而**预判对手的攻击与行动**。作中有"像热成像一样看得见"的表现描述。【B】
  - https://ciatr.jp/topics/324209
  - https://comicjiten.com/rikugan/
- **"六眼 + 无下限"在同一人身上出现是 400 年一遇**；且**同一时代只能存在一位六眼持有者**（这是原作给出的制约）。【B】
  - https://manga-tantei.com/jujutsukaisenrikugan-15994
  - https://comicjiten.com/rikugan/
- **这是五条"咒力用不完"的真正原因**：无下限需要 24 小时、原子级的超精密计算，普通术师去用会当场"脑烧毁"；六眼充当了那台超高性能术式的"电池兼 CPU"，使**咒力消耗几乎为零、术式可被完全控制**。【B】
  - https://ameblo.jp/cocoa-animerank/entry-12970138078.html
  - https://sacchinjaiblog.com/gojosatoru08/
- 五条**用反转术式持续修复大脑**，才能把无下限做成"24 小时常时发动"；六眼（自动识别危险）＋无下限（只挡危险物）＋反转术式（不断修复大脑）**三者齐备**才成立"24 小时无敌屏障"。【B】
  - https://ai-pick.jp/17782/
- 补充：**学生时代的五条无法 24 小时常时发动**，只能按需 ON/OFF（怕脑负荷），那段"OFF 的瞬间"就是他的弱点。这解释了"六眼≠一开始就无敌"。【C】
  - https://anigala-rew.jp/column/jujutsukaisen20260319/

**视觉表现**
- 平常以眼罩/墨镜遮眼（六眼信息量过大）。战斗中露出时是苍蓝色瞳孔特写；六眼启动时常配"信息流入"的眼部特写与瞳孔纹样。
- 解说站描述其感知为"热成像式"的咒力可视化。【B】https://ciatr.jp/topics/324209

**限制与代价**
- 没有六眼 → 无下限基本无法运用（这是"五条家每 400 年才出一个能用的"的原因）。
- 六眼本身**不提供防御**，只提供信息与效率。
- 一场只能有一个六眼持有者（世界设定级约束，游戏里不必实现，但可做演出）。

**游戏机制落地建议**
- 做成**资源效率型被动**，而不是"全知"：六眼 = 咒力消耗 -80%~-90%、技能后摇/咏唱时间缩短、敌方前摇预警可视化（读招窗口 +0.1s）。
- 绝对**不要**做成"自动闪避一切"——那会让操作失去意义（见 §6）。
- 可以做成"**开关式**"：开局前 30 秒或某阶段前无法常时开启（还原学生时代），玩家需主动管理 ON/OFF，做成一个节奏资源。

### 1.2 無下限呪術（Infinity / 不可侵）

**原作里具体怎么运作**
- 五条家相传的**生得术式**。原理是把数学上的**"阿基里斯与龟"式收敛无限级数现实化**：在术者与对象之间的"概念上的相对距离"上插入无限，使对象**永远无法真正抵达**。原作称这种状态为**"不可侵"**。【A/B】
  - https://dic.pixiv.net/a/%E7%84%A1%E4%B8%8B%E9%99%90%E5%91%AA%E8%A1%93
  - https://comicjiten.com/mukagenjyujyutsu/
  - 五条本人在动画第 26 话（懐玉－弐－）用"阿基里斯与龟"举例说明：https://likiroku.com/jujutsu-26-akiresu/
- **不是"贴一层屏障"，而是空间层面的距离操作**；越接近速度越趋近于零。原作说明强调这是"空间的收束/发散"。【B】
  - https://likiroku.com/jujutsu-26-akiresu/
  - http://likiroku.com/jujutsu-gojou-nouryoku/
- **只挡"被术者判定为危险的东西"**：若不判定就会连氧气一起挡掉（所以不是绝对无脑的球形力场）。【C】
  - https://ai-pick.jp/17782/
- **衍生能力**：空中浮游、瞬间移动（把无限/收束用在移动上）。【B】http://likiroku.com/jujutsu-gojou-nouryoku/
- **咒词**（顺转使用时）：「位相 黄昏 智慧の瞳」。【B】https://dic.pixiv.net/a/%E7%84%A1%E4%B8%8B%E9%99%90%E5%91%AA%E8%A1%93
- 原作明言其**操作难度极高**："看起来万能，其实是五条本人的天分与努力的结晶"，不是术式本身无脑强。【B】https://dic.pixiv.net/a/%E7%84%A1%E4%B8%8B%E9%99%90%E5%91%AA%E8%A1%93

**视觉表现**
- 攻击在触及五条前**减速、停滞、悬空**，画面常给"刀锋停在半空/拳停在脸前"的特写；空气有扭曲/折射感。空间系招式（苍/赫）以黑红光球与吸斥形变呈现。

**限制与代价**
- **必须要六眼**（见 §1.1）。
- **24 小时维持需要反转术式修复大脑**，否则脑负荷爆炸。
- **会被"领域展延"中和**（原作里宿傩就是用这招打穿无下限的，见 §1.7）。
- **会被"扩展术式对象"的攻击绕过**——即宿傩最终的"世界を断つ斬撃"（连空间一起切，则"无限距离"这个防御前提失效）。【B】
  - https://lanoveto-animeto-watashi.com/2026/07/20/jujutsu-kaisen-satorugojo/
- **领域中并非万能**：在领域内部，无下限的"不可侵"与领域的必中效果会发生复杂的抵消关系（见 §4）。

**游戏机制落地建议**
- 做成**"距离阈值/减速场"机制**，而不是无敌帧：
  - 敌人进入以五条为圆心的半径 R 后，**移动速度、弹道速度按接近度连续衰减**（视觉上做出"子弹停在空中"）。
  - 用**"穿透类型"标签**克制：领域展延类、空间切断类、必中类可无视减速场 —— 这正是原作的破解逻辑，既还原又给玩家解法。
- 代价：常时开启持续消耗"脑负荷"条，脑负荷满 → 减速场短暂失效（还原 OFF 的瞬间）。这是**最有原作味的资源循环**。

### 1.3 術式順転「蒼（あお）」

**原作里具体怎么运作**
- 无下限的**强化形态**：把"收束"现实现象化，**产生吸引/吸附力**，能把周围夷为平地。【B】
  - https://dic.pixiv.net/a/%E8%A1%93%E5%BC%8F%E9%A0%86%E8%BB%A2%E3%80%8C%E8%92%BC%E3%80%8D
- 五条最常用的用法是**把"蒼"叠在打击上**：拳/膝命中瞬间用蒼把对手吸进来，提升打击威力。【B】同上
- **弱点明确**：无法在自己身边产生大规模反应（即不能近身自爆式使用）。【B】同上
- **高光**：9 卷 71 话 vs 伏黑甚爾（第一次真正展示蒼的威力）。【B】https://ciatr.jp/topics/317691
- 236 话：五条放出**输出最大的「蒼」**直击式神"顎吐"。【B】https://manga-games.com/jujutsukaisen-jump-236/

**视觉表现**
- 掌中/拳上出现**苍蓝色（偏黑）的引力球**；被吸引的碎石、血、敌人身体向球心弯曲；命中时为吸附式压缩打击。
- 用于移动时表现为"把自己吸向目标"的高速位移。

**限制与代价**
- 近身无法大出力（原作明示的弱点）。
- 需要咏唱/掌印才能提升威力（223 话 200% 茈的场合是"不省略咒词·掌印·舞"）。

**游戏机制落地建议**
- **核心近战强化 buff + 位移技**：蒼 开启后普攻附带"吸附"（把敌人往自己/往命中点拉），并给一个"向目标冲刺"的机动技。
- 把"近身无法大出力"做成**明确的机制约束**：距离 < X 时蒼的伤害/范围衰减 → 逼玩家用位移拉开距离，形成"贴脸-拉开"的操作循环。**不要**取消这条，它是原作给的角色特征。

### 1.4 術式反転「赫（あか）」

**原作里具体怎么运作**
- 与蒼相反，**把无限发散**，产生**排斥力**，把对象吹飞。【B】
  - https://dic.pixiv.net/a/%E8%A1%93%E5%BC%8F%E5%8F%8D%E8%BB%A2%E3%80%8C%E8%B5%AB%E3%80%8D
- **威力是顺转（蒼）的两倍**，因此**在街市等场合会被限制使用**（附带破坏太大）。【B】同上
- **术语辨析（很重要，别写错）**：
  - **術式反転**＝把术式效果反转（蒼 → 赫），是"术式的反转"。
  - **反転術式**＝把负的咒力相乘产生正能量，用于治疗（见 §1.9）。
  - 两者是不同的东西。【B】https://gensakuwomitai.net/jujutsukaisen-jutsushikihanten/ ／ https://www.anime-rating.com/30551/
- 226 话：五条在自己领域被破后**用「赫」反打宿傩**。【C】https://forum.gamer.com.tw/C.php?bsn=48102&snA=1849

**视觉表现**
- 鲜红色的斥力爆闪；対象被放射状吹飞，地面呈放射状龟裂；配合"赫"的咏唱时画面会有红色能量汇聚。

**限制与代价**
- 威力是蒼的两倍 → **附带损害大**，原作明示在城市中受限（游戏里可做成"自伤/场景破坏"的代价）。
- 依然依赖六眼的精密控制。

**游戏机制落地建议**
- **击退/破防技**：高伤害 + 大击退 + 破甲，但**有自伤或场景惩罚**（例如在室内/狭窄场地使用会伤及自身或引发塌方）。
- 与蒼组成**"吸-斥"二择**：蒼拉近打连段，赫推开重置距离。这是原作最有辨识度的一对，机制上天然互补。

### 1.5 虚式「茈（むらさき）」

**原作里具体怎么运作**
- 让**顺转（蒼）与反转（赫）的力量相撞**，生成**假想的（虚构的）质量**并推出去的**复合术式**；**五条家内部也只有一部分人知道**。【B】
  - https://dic.pixiv.net/a/%E8%99%9A%E5%BC%8F%E3%80%8C%E8%8C%88%E3%80%8D
- **223 话的 200% 茈（开战第一击）**：
  - 前置：**庵歌姫的术式增幅**（咒力总量与输出的临时提升）＋ **伊地知的结界**制造奇袭 ＋ 楽巌寺学長的支持。
  - 五条**不省略咒词、掌印、舞**（=自我束缚/縛り，用来把威力拉到 200%）。咒词为**「九綱」「偏光」「烏と声明」「表裏の間」**。
  - 射程表现：**从约 4km 外的楼对楼发射**的长距离炮击，直击宿傩。【B/C】
  - 来源：https://character-holic.com/jujutsu/gojo_jushi/ ／ https://comicjiten.com/jujutsukaisen223/ ／ https://introduction1.com/2023/05/22/jujutsu223/ ／ https://note.com/yakikoimo/n/n440612a79297
- **234 话**：五条还藏着一张"**無制限の虚式**"的底牌（与茈不同的东西）。【C】
  - https://anime-drama.jp/24220 ／ https://www.toyotetsu.net/jujutsukaisen234/
- **⚠️ 中文互联网上有一条错误说法**：某文库页面称"200% 茈是乙骨忧太操纵五条遗体时放的"。**这是错的**——223 话的 200% 茈是五条本人放的第一击；乙骨进入五条遗体是 **261 话**的事。【B】
  - 错误来源（请勿采信）：https://wenku.baidu.com/view/7eacbb6987c4bb4cf7ec4afe04a1b0717fd5b30c.html
  - 正确时间点来源：https://eiga-manga.com/entry/jujutsu261

**视觉表现**
- 蒼（黑蓝）与赫（红）两种能量**对撞**后生成紫色/白色的假想质量球，射出时为**贯穿式光束/巨大能量弹**，沿途一切被抹平。223 话是天际线级别的长距离轨道炮。

**限制与代价**
- **复合术式，门槛极高**（五条家内部都只有部分人知道）。
- **要打出 200% 必须"不省略咒词·掌印·舞"** → 意味着**咏唱时间/前置仪式是硬代价**（游戏里最好做成可见的长前摇）。
- 需要外部增幅（歌姫）才能到 200% → 游戏里可做成"队友 buff 才能解锁的终极技"。

**游戏机制落地建议**
- **终极致命一击（大招）**：长前摇 + 固定弹道 + 极高伤害，**可被闪避/被换阶段打断**。
- 强烈建议做成**"剧情演出技"而非常规连段**（见 §6）：原作里茈是"底牌/仪式感"的东西，做成随手可发的普攻会毁掉它的分量。
- 200% 版本做成**关卡机制**：需要玩家先完成前置条件（队友 buff/结界布置），再释放 —— 直接把 223 话的战术还原成关卡目标。

### 1.6 領域展開「無量空処（むりょうくうしょ）」

**原作里具体怎么运作**
- **效果（原作说明）**：**强制知觉与传达进行无限次作业**。进入领域者**五感全部被灌入无限的信息**，结果**什么都做不了、连动都动不了**。等价于"夺走敌人的五感"。【B，转引原作说明】
  - https://ciatr.jp/topics/324234
- **首次登场**：原作 2 卷 15 话，对漏瑚。【B】同上
- **涩谷事变（11 卷 89 话）的"0.2 秒"**：
  - 五条在一般人、改造人类、特级咒灵混杂的地铁里**即兴只展开 0.2 秒**，把对普通人的影响压到最小，同时定住对手；**0.2 秒是五条"凭感觉"设定的、非术师能安全承受的滞留时间**。
  - 结果：**299 秒内歼灭改造人类 1000 体**。【B】
  - 来源：https://dic.pixiv.net/a/%E7%84%A1%E9%87%8F%E7%A9%BA%E5%87%A6 ／ https://zen-seer.com/?p=11806
- **手印**：**五条是单手结印**（宿傩、真人是双手）。【B】https://ciatr.jp/topics/324234
- **名字元ネタ**：佛教用语「空無辺処」。【C】同上
- **宿傩战**：25 卷 225 话起使用。【B】同上
- **领域对拼时的机制（关键）**：两个领域同时展开时，**在五条的结界内部，两边"必中命令"互相重复而被抵消**；一旦哪一方受重创导致领域崩坏，**另一方的必中术式就会立刻命中**。【B】
  - https://manga-games.com/jujutsukaisen-jump-225/

**视觉表现**
- 领域内是**无限延展的黑色/星空状空间**，中央有巨大的球体结构，无数光点/信息流涌入；敌人呈僵直、瞳孔涣散、"信息过载"的静止状态。
- 领域外壳为**球状结界**（可被外部破坏 —— 这是五条的战术弱点）。

**限制与代价**
- **领域外壳是封闭球体** → **会被"开放型领域"（伏魔御厨子）从外部打碎**（原作 225 话就是如此）。【B】https://introduction1.com/2023/06/12/jujutsu225/
- **对非术师有致命影响** → 使用时必须控制时长（0.2 秒）与范围。【B】https://dic.pixiv.net/a/%E7%84%A1%E9%87%8F%E7%A9%BA%E5%87%A6
- **领域被破后会术式熔断（术式无法立即再用）** → 领域战失利等于一段时间内失去最大底牌。
- 领域展开本身**消耗巨大**。

**游戏机制落地建议**
- 做成**"控制型领域"而非秒杀**：进入领域范围内的敌人 → 行动不能 / 动作被冻结 N 秒，而不是直接死亡（原作效果正是"什么都不能做"，不是"被杀死"）。
- 做成**阶段机制**：BOSS 战里五条展开领域 → 玩家必须**从外部打破结界**（还原 225 话宿傩的解法）→ 这是极好的关卡交互。
- **0.2 秒**做成一个可操作的技术点：玩家可主动把领域时长压到极短（换取"不误伤/冷却更短"）。这是原作里五条最聪明的一次操作，值得做成技巧上限。

### 1.7 領域展延（りょういきてんえん）

**原作里具体怎么运作**
- 定义：**把"不附带术式的领域"像一层水膜一样裹在自己身上**，用来**中和接触者的术式效果 / 领域的必中效果**。原理是把对手的术式流进"领域开着的容量"里中和掉。【B】
  - https://kero-entame-channel.hatenablog.com/entry/2022/01/22/180000
  - https://manga-tantei.com/jujutasukaisenryouikitenen-19107
- **发动中不能使用生得术式，只能物理攻击**（这是它的代价）。【B】
  - https://hamamachi.jp/jyujyutukaisen-ryouikitenen-gojyou-ataru/
- **原作中它正是作为"无下限咒术的对策"登场的** —— 宿傩在 225 话用领域展延发起进攻，中和无下限后试图斩到五条。【B】
  - https://manga-tantei.com/jujutasukaisenryouikitenen-19107
  - https://comichronicle.com/jujutsu-225/
- **⚠️ 存疑条目**：**五条本人是否使用过领域展延，来源互相矛盾。**
  - 一边：有解说视频标题直接说"五条悟一次也没用过领域展延"，并给出理由。【C】https://www.youtube.com/watch?v=dL8DSOJ2Vzc
  - 另一边：也有站点讨论"领域展延 → 五条悟被这样攻击"，用于解释宿傩的手法。【B】https://hamamachi.jp/jyujyutukaisen-ryouikitenen-gojyou-ataru/
  - **结论：未能确认五条使用过领域展延。【未找到可靠来源（定论）】**
  - 顺带：也有"五条不能用领域展延"的讨论文章存在。【C】https://ciatr.jp/topics/324572

**视觉表现**
- 身体表面覆上一层极薄的、透明的水膜/薄膜质感；接触时对手的术式"熄火"。

**限制与代价**
- **不能同时用生得术式**（五条若用，就必须暂时放弃无下限/蒼/赫）。
- 只中和"接触到的"，不是远程无效化。

**游戏机制落地建议**
- 做成**"破防/切换形态"机制**：开启后**免疫/中和对手的必中与术式伤害**，但**自己的术式攻击全部封锁，只能肉搏**。
- 这是**最好的"BOSS 破解手段"**：玩家面对五条式 BOSS 时，用展延近身肉搏；反之五条作为玩家角色时，展延是一个"高风险换血"选项。
- 对**无下限**的克制关系必须做进去 —— 否则无下限在游戏里就没有解法（这是原作的核心博弈）。

### 1.8 黒閃（こくせん）

**原作里具体怎么运作**
- 定义（原作 127 话给出）：**打击与咒力的误差被压到 0.000001 秒以内时产生的空间扭曲**。发生时咒力**如黑色闪电般迸发**。【A/B】
  - https://dic.pixiv.net/a/%E9%BB%92%E9%96%83
  - https://jujutsu-kaisen.fandom.com/ja/wiki/%E9%BB%92%E9%96%83
  - https://entame-life.com/jujutsu-kokusen/
- **威力：平均为通常攻击的 2.5 乗**。【B】https://dic.pixiv.net/a/%E9%BB%92%E9%96%83
- **它是"现象"，不是"技"**：术师、咒灵都能发生；**没人能稳定地故意打出**。【B】
  - https://gensakuwomitai.net/jujutsukaisen-kokusen/
- **打中之后的收益（很重要）**：术师会进入类似运动员"**zone**"的状态 —— 呼吸般自然地炼咒力，**战斗力显著提升**。【B】
  - https://subculview.com/jujutsu-kokusen-abilities
- **五条在宿傩战中合计打出四度黑闪**（"計四度の黒閃を決めた事で五条のボルテージは上がる"）。【B】
  - https://dic.pixiv.net/a/%E5%8D%97%E3%81%B8%28%E5%91%AA%E8%A1%93%E5%BB%BB%E6%88%A6%29
- 232 话：五条的黑闪直击宿傩、造成让其**昏厥级别**的大伤害。【B】
  - https://introduction1.com/2023/08/21/jujutsu232/
- 宿傩侧：**256 话宿傩对真希连发黑闪**；257 话宿傩与虎杖黑闪对轰。【B】
  - https://entame-life.com/jujutsu256/ ／ https://entame-life.com/jujutsu257/

**视觉表现**
- 命中瞬间**黑色闪电**从接触点迸裂，画面常配反白/黑闪高对比帧、短促静音后爆音。

**限制与代价**
- **不可稳定主动命中**（原作明确：没有人能狙って出す）。
- 一旦成功，收益是"进入 zone"（咒力操作效率跃升），而不是单纯伤害。

**游戏机制落地建议**
- **这是最适合做成核心操作系统的原作设定**：
  - 判定窗口**极窄（例如 3 帧）**的"精准命中" → 触发黑闪 → 伤害 ×2.5 并进入 10 秒 zone（咒力消耗降低、动作加速）。
  - **不要做成随机**（原作是"技术极致"的象征）；做成**难但可练**，就是最好的技巧上限。
  - 可加**软保底**降低挫败：连续 N 次精准命中未触发时，窗口略微放宽（对玩家友好，且不与"没人能稳定打出"的原作描述冲突）。

### 1.9 反転術式（はんてんじゅつしき）

**原作里具体怎么运作**
- 原理：**把负的咒力相乘（負×負）产生"正"的能量**。因此它是**正能量**，与咒灵相性极差（能对咒灵造成特攻级效果）。**能实现通常咒力做不到的"肉体再生"**。【B】
  - https://likiroku.com/jujutsu-gojo-hantenjutsushiki/
  - https://manga-tantei.com/jujutsukaisenhantenjutsushiki-13391
- **五条何时学会**：高专二年级，"懐玉・玉折"篇与**伏黑甚爾**的死斗中，**濒死时**才真正掌握（此前原理懂但做不到）。【B】
  - https://note.com/clean_broom424/n/n4bdd35362d2e
  - https://likiroku.com/jujutsu-gojo-hantenjutsushiki/
- **五条的用法**：**持续用反转术式修复大脑**，从而维持无下限的常时发动；也用于治疗自身伤势。【B】
  - https://ai-pick.jp/17782/
  - http://likiroku.com/jujutsu-gojo-hantenjutsushiki/
- **治疗他人比治疗自己难得多**（精度与效率大幅下降）；五条属于**只能自我治疗**的类别。【B】
  - https://dic.pixiv.net/a/%E5%8F%8D%E8%BB%A2%E8%A1%93%E5%BC%8F
  - https://zen-seer.com/?p=11910
- 能处理的不仅是外伤，还包括**高难度的解毒**。【B】https://manga-tantei.com/jujutsukaisenhantenjutsushiki-13391

**视觉表现**
- 伤口处浮现柔和的金色/白色光，组织以不自然的顺序愈合；五条头部（大脑）治疗时常有头部特写。

**限制与代价**
- **消耗咒力**；治疗他人效率大幅下降。
- **不能治疗"灵魂"层面的损伤**（原作基调：反转术式是肉体再生）。
- 五条在领域战中被斩后是**一边吃伤害一边开反转术式治疗**，同时还得分配咒力去对抗领域。【C】https://forum.gamer.com.tw/C.php?bsn=48102&snA=1849

**游戏机制落地建议**
- 做成**"咒力换血"**：消耗咒力槽回血，回血期间**动作受限/防御下降**（原作里治疗=分配资源，不是免费）。
- 与"无下限常时开启"绑定：**脑负荷条 = 反转术式维持量**，玩家要在"防御/治疗/进攻"之间分配同一份咒力——这就是五条这个角色的核心玩法循环。
- 自我治疗 vs 他者治疗做成不同效率（他者治疗更贵），还原原作的不对称。

### 1.10 呪力操作与体术

- **核心结论：五条的"无敌"是三件套的组合**——六眼（识别+效率）＋无下限（免疫）＋反转术式（修复大脑）。**缺一件就不成立**。【B】https://ai-pick.jp/17782/
- **咒力消费几乎为零**、术式可完全控制，是六眼带来的效率。【B】https://sacchinjaiblog.com/gojosatoru08/
- **体术层面**：六眼能预判对手攻击与行动，**这是一切基础体术战的前提**（原作解说直接这么说）。【B】https://ciatr.jp/topics/324209
- **黑闪后的 zone 状态**使咒力操作变得"像呼吸一样"。【B】https://subculview.com/jujutsu-kokusen-abilities
- 五条在宿傩战中的**体术阶段**（领域互崩后的肉搏战）被概括为"ラウンド2"：双方在都不能用领域的状况下以术式+肉搏对拼。【B】
  - https://dic.pixiv.net/a/%E5%8D%97%E3%81%B8%28%E5%91%AA%E8%A1%93%E5%BB%BB%E6%88%A6%29

**游戏机制落地建议**
- 五条应设计为**"资源三线管理"角色**：咒力槽（攻击/反转术式共用）、脑负荷（无下限维持）、黑闪 zone（增益窗口）。
- 体术不要做成弱项：原作五条在徒手对拼中并不落下风（甚至靠黑闪压制宿傩）。建议**攻速中上、单发伤害中、靠 zone 与吸附连段滚雪球**。

## 2. 両面宿儺（りょうめんすくな）

### 2.0 总览：宿儺的"术式骨架"

- 生得术式是**「御廚子（みづし）」**，能力**大致分为"斩击"与"炎"两类**。斩击再分**「解」**与**「捌」**；炎系是**「開（フーガ）」/「竈（カミノ）」**。【B】
  - https://comicjiten.com/mizushi/
  - https://asobigokoro.work/Anime-Manga/jujutsu-kaisen-ryomen-sukuna-techniques-mizushi-kamino/
- 在新宿决战期间，宿儺**受肉于伏黑惠的肉体**，因此**能使用十种影法術**。【B】
  - https://asobigokoro.work/Anime-Manga/jujutsu-kaisen-ryomen-sukuna-techniques-mizushi-kamino/

### 2.1 解（カイ）—— 通常斩击

**原作里具体怎么运作**
- **飞出的斩击，可自由操控**（自在に繰り出す）；**用手掌定向可提升出力**，但**无预备动作（ノーモーション）也能发动**。【B】
  - https://comicjiten.com/mizushi/
- 定位是"**通常的物理斩击**"：非常强，人体自不必说，车、建筑物都能轻易两断；**发动速度快到"斩击的启动不被描写"**，宿儺摆好姿势时对方已经被切断。【B】
  - http://likiroku.com/jujutsu-sukuna-kai-hachi/
- **⚠️ 重要的形态差异**：**"世界を断つ斬撃"也是「解」**——是**把「解」的术式对象从"目标个体"扩展到"空间/世界本身"**的版本（见 §2.5）。【B】
  - https://mangafriend.com/jujutsu427sekaiwotatsu/
- **使用者可被他人复制**：250 话中**乙骨忧太在自己的领域「真贋相愛」里复制了「捌」并对宿儺使用**。【B】
  - https://mangafriend.com/jujutsu485hachikai/

**视觉表现**
- **不可视/极难察觉**的斩击线（原作强调"看不见"）；被切断的物体在延迟一拍后滑落，切面极其平整。
- 大范围使用时是**网状的连续斩击**，建筑物像被切豆腐一样成块滑落。

**限制与代价**
- 解**没有"必中"**（必须自己瞄准/铺设轨迹），必中效果来自领域。
- 输出与"手掌定向"相关（游戏里可以做成"瞄准方向影响伤害"）。

**游戏机制落地建议**
- **基础远程攻击**：低前摇、不可视（用音效/空气扭曲给出 2~3 帧前兆）。
- 做"**方向加成**"：手动瞄准（掌）时伤害提升，无瞄准时是快速散射 → 让玩家有操作取舍。

### 2.2 捌（ハチ）—— 按对象调整的斩击

**原作里具体怎么运作**
- **按对象的咒力 / 强度自动调整，一刀"卸开"对象**（対象の呪力に応じ自動調整される攻撃）。【B】
  - http://likiroku.com/jujutsu-sukuna-kai-hachi/
  - https://mangafriend.com/jujutsu485hachikai/
- 社区对"解 vs 捌"的常见理解（**粉丝推论，非官方明示**）：**捌的威力随对手强度/咒力量变化**，用于把弱对象"切成碎块"、对强对象效率可能变差；**解是稳定的常规伤害**。有讨论认为**对五条这种对手，捌效率反而差**，所以宿傩改用解。【C】
  - https://animanch.com/archives/20932275.html
  - https://sprite289.hateblo.jp/entry/2023/04/04/003235
- **⚠️ 原作没有给出"捌"的完整数值化说明**；上述强弱关系均为读者分析。【未找到可靠来源（官方定义）】

**视觉表现**
- 与解类似，但常表现为**针对性的、贴合对象形状的切割**（"卸す"＝像料理一样分解）。

**限制与代价**
- 依对象而变 → **不是稳定高伤手段**。

**游戏机制落地建议**
- 做成**"按目标属性换算伤害"的机制斩**：
  - 对**低血量/低防御的杂兵** → 直接处决/粉碎（还原"一刀卸开"）。
  - 对**高防御/高咒力量的 BOSS** → 效率下降 → 逼玩家切换成解/火焰。
- 这是很好的"**让玩家自己发现解与捌该用哪个**"的设计，而不是把两个技能做成同一件事换皮。

### 2.3 開（フーガ）／竈（カミノ）—— 火焰箭

**原作里具体怎么运作**
- **「開」是炎的矢（火焰箭）**；与**「竈」**成对，用来**以超高温烧尽目标**，是宿傩的"最终奥义/王牌"级手段。【B】
  - https://ciatr.jp/topics/329853
  - http://likiroku.com/jujutsu-40-sukuna-fuga/
- **首次披露**：涩谷事变（动画 40 话「霹靂」，原作对**漏瑚**）。【B】http://likiroku.com/jujutsu-40-sukuna-fuga/
- **使用序列（粉丝分析，但是流传最广的解释）**：先以**解与捌**处理对手，**对手仍存活**时才开「竈」。原作中「開」只对**漏瑚**与**魔虚羅**用过 —— 这两者的共同点正是"**吃了 解+捌 还没死**"。【C】
  - https://xn--eckwa2aa9g7g4c.com/?p=83699 （原站为日文域名「マンガ好き.com」，检索命中的等价链接）
  - 另一解说：https://anicomigamania.com/ (両面宿儺の最終奥義「竈カミノ開フーガ」解説)
- **宿傩在五条战中"没有使用"「開」** —— 多个解说站明确指出，普遍解释为"**留给后续术师群的底牌**"。【B/C】
  - https://eiga-manga.com/entry/jujutsu-kamino-fuga
  - https://detail.chiebukuro.yahoo.co.jp/qa/question_detail/q13285477213

**视觉表现**
- 巨大的**火焰箭/火焰柱**；高温使空气扭曲、目标被瞬间烧尽。与斩击的"无声切割"形成强烈对比（火焰是明亮、可见的攻击）。

**限制与代价**
- **前置条件**（粉丝共识）：需要先用解/捌"处理"过对手（有解说也提到需要"解与捌的工序"经过后才开灶）。【C】
  - https://yuruyurumedia.com/j-kaisen/original1013/
- **原作对"開"的术理说明极少** —— 它长期是一个悬念。（解说站也承认宿傩"御廚子"的全貌"不明点很多"。）【B】
  - http://likiroku.com/jujutsu-sukuna-kai-hachi/
  - https://ciatr.jp/topics/329853

**游戏机制落地建议**
- **做成"处决技/斩杀确认"**：对**已被斩击削减到一定血量以下**的敌人才能发动 → 完美还原"解和捌弄不死才开灶"。
- **绝对不要做成"瞬发大火球"**：那会让宿傩的斩击特色消失。
- 因为原作对"開"的描写很省，游戏里**有较大自由度**，但请保留"高前摇、高伤害、火焰可见"这三个特征。

### 2.4 領域展開「伏魔御廚子（ふくまみづし）」

**原作里具体怎么运作**
- **开放型领域**：**不用结界分隔空间**，直接把生得领域具现到现实。代价是**允许人自由进出领域**，换来的是**最大半径约 200m 的巨大必中攻击范围**，且**这个范围可以被精密控制**。【B】
  - https://dic.pixiv.net/a/%E4%BC%8F%E9%AD%94%E5%BE%A1%E5%BB%9A%E5%AD%90
  - https://ciatr.jp/topics/324389
  - https://baike.baidu.com/ja/item/%E4%BC%8F%E9%AD%94%E5%BE%A1%E5%8E%A8%E5%AD%90/1417756
- **领域内会按对象的性质，连续施放「捌」与「解」的斩击**。【B】
  - https://db.mangalab-cocona.com/articles/jjk-sukuna-domain-expansion
- **表现**：发动时出现**以各种生物头骨装饰的寺庙/佛堂**。【B】https://dic.pixiv.net/a/%E4%BC%8F%E9%AD%94%E5%BE%A1%E5%BB%9A%E5%AD%90
- **「不闭合的领域」的类比解释**（原作/解说常用）："**不用画布在空中作画**""**不用容器蓄水**""**不用硬件播放软件**"。【B】同上
- **五条对它的评价**：称其为"**神業**"。【B】https://anime-lab.net/jujutsu-mizushi/
- **涩谷事変中的实绩**：展开时半径约 **140m**，广范围破坏建筑与道路，并造成大量一般人受害。【B】
  - https://content-station.net/shibutanizihennosukunahananiwoshitahukkaturiyuukaramakyorasenitadoriwooitumetakoudoumadeseiri/
- **对五条的战术意义（关键）**：因为它是开放型、**领域外壳向外延伸得更远，可以从外部破坏五条的封闭结界** → 225 话就是这样破了五条的领域。【B】
  - https://introduction1.com/2023/06/12/jujutsu225/
  - https://forum.gamer.com.tw/C.php?bsn=48102&snA=1849
- 领域对拼时：**在五条结界内部，双方的"必中命令"互相重复、相互抵消**；谁先受重创导致领域崩坏，谁的必中就会立刻命中对方。【B】
  - https://manga-games.com/jujutsukaisen-jump-225/

**视觉表现**
- 白骨装饰的寺庙空间、巨大的黑色灶/御厨子结构、斩击以**无死角的网状白光**在场景中来回切割。
- 因为是开放型，**背景仍然是新宿的实景**（不像普通领域那样被完全替换） —— 这点在游戏里非常有辨识度。

**限制与代价**
- **允许敌人自由进出**（安全性换范围）。
- **领域被破 = 术式熔断**（一段时间不能再用领域）。
- 领域是巨大消耗。

**游戏机制落地建议**
- **这是最适合做成"关卡级机制"的领域**：
  - 开放型 = **不封闭战场**，玩家可以逃出范围（原作正是如此），但**范围内持续被斩**。
  - 做成"**范围压制 + 逼迫玩家离开有利位置**"的机制，而不是"进圈即死"。
  - 视觉上保留"**新宿街景 + 白骨佛堂叠加**"的开放领域，和五条的"全黑信息空间"形成舞台级对比（天然的关卡双阶段）。
- "从外部打破对手领域"的交互**必须做**（这是 225 话的核心，也是玩家战胜五条领域的唯一正解）。

### 2.5 世界を断つ斬撃（空间斩 / 习得后的「解」）

  - https://syntelligence.jp/article/124213
  - https://asobigokoro.work/Anime-Manga/jujutsu-kaisen-ryomen-sukuna-techniques-mizushi-kamino/
- **效果**：**236 话把五条一刀两断（真っ二つ）**，五条死亡。【B】

  - https://gamepedia.jp/story/archives/1312

  - https://daddyjim.ai/ja/who-would-win/gojo-vs-sukuna

**视觉表现**

- 236 话的名场面：五条**上半身与下半身分离**倒在血泊中；宿儺说出"天晴れだ五条悟"。【B】

**限制与代价**

**游戏机制落地建议**

- 若要做成可操作内容，只能作为**最终阶段的一次性机制**（例如：BOSS 进入 P3 后，玩家的"无下限"防御被永久标记为"可被切断"，玩家必须在被命中前打断其蓄力）。
- 这是全篇最该"演出化"的一招（见 §6）。

### 3.2 「适应」到底怎么运作（原作机制）

**原作台词（转引自动画第 41 话「霹靂-弐-」）** —— 这是最接近"原作原文"的证据：
> 宿儺「**布瑠の言とあの法陣は、完全な循環と調和を意味する。推し量るに、この式神の能力は、あらゆる事象への適応。最強の後出し虫拳**」
> （布瑠之言与那个法阵，意味着完全的循环与调和。推量起来，这个式神的能力是——对一切事象的适应。最强的后出猜拳。）
> 来源（转引）：http://likiroku.com/jujutsu-41-sukuna-vs-makora/ ／ http://likiroku.com/jujutsu-makora/

### 3.4 【重点】"原作里魔虚羅没有血条"—— 支持与反驳

任务书要求就这一点找出原文证据支持或反驳。**结论：部分支持，部分反驳，且两部分都能追到来源。**

#### ✅ 支持的部分（"它不靠耐久，靠适应定胜负"）

1. **原作给出的能力定义就是"适应"，而不是"耐久"。** 宿儺的台词把它的本质定义为"**对一切事象的适应**"，并称之为"**最强的后出猜拳**"。
   - **"后出猜拳"这个比喻，本身就是"后手必胜、不吃数值"的机制描述。**【A/B】
   - http://likiroku.com/jujutsu-41-sukuna-vs-makora/
2. **胜负点在"适应是否完成"，而不是"打了多少血"。** 逐话旁白是"**再转 N 次，适应就完成了**"这种**倒计时**表述，而不是"血量还剩多少"。【B】
   - https://www.sirolog.com/entry/2023/08/21/jyujyutukaisen232/
   - https://manga-games.com/jujutsukaisen-jump-232/
3. **"第一发能进，之后就没戏了"的结构**，意味着**它不是靠血厚，而是靠"免疫累积"**。【C】
   - https://buzz-beaver.com/2023/08/01/呪術廻戦-230話考察/
4. **原作里确实从未给出魔虚羅的耐久数值 / HP 概念**，也没有"削血"式的描写。**本次检索未找到任何"魔虚羅血量/耐久"的官方数据。**【未找到可靠来源 —— 即：反驳方也拿不出"血条"证据】

#### ❌ 反驳的部分（"它并非打不死，也并非'适应完就自动赢'"）

1. **它是有实体、会被破坏的。**
   - **涩谷事変**：宿儺最终**击破了魔虚羅**。【B】
     - https://content-station.net/jujutukaisennomatoraramakoratohanouryokutekiounoshikumiyahusekurogayobidasetariyuuwokaisetu/
     - https://chaca.jp/jujutsukaisen-119/
   - **新宿决战**：**五条以最大出力的虚式「茈」将魔虚羅完全破坏**。【B/C】
     - https://syntelligence.jp/article/125917
     - https://syntelligence.jp/article/124213
2. **"适应完就赢"在原作里被证伪过**：涩谷事変中魔虚羅**已经适应了「解」**，宿儺仍通过**切换攻击性质**把它解决 ——
   - 解说的表述是：**宿儺"在它完全适应某一种攻击之前，切换到另一种性质的攻击"**。【B】
     - https://content-station.net/jujutukaisennomatoraramakoratohanouryokutekiounoshikumiyahusekurogayobidasetariyuuwokaisetu/
   - 而那"另一种性质的攻击"普遍被认为是**「開」的火焰**（因为「開」只对"吃过解+捌还不死"的对手使用）。【C】
     - https://xn--eckwa2aa9g7g4c.com/?p=83699
   - **即：适应的对象是"那一种事象"，不是"所有伤害"。**
3. **它对"完全没见过的、高强度的攻击"无法应对** —— 这是所有解说都同意的弱点。【C】
   - https://wenku.baidu.com/view/7aa68005fa4733687e21af45b307e87100f6f855.html
4. **"适应完成"在剧情层面的确导向了宿儺的胜利，但那是"宿儺拿走了适应的成果"，不是"魔虚羅自己赢了"**：宿儺**以魔虚羅的适应轨迹为范本，完成了「世界を断つ斬撃」**。【B/C】
   - https://syntelligence.jp/article/124213

#### 📌 给关卡设计的结论

| 说法 | 判定 | 说明 |
|---|---|---|
| "原作里魔虚羅没有 HP/血条概念" | **支持** | 原作从未给耐久数值；胜负由适应进度决定；旁白用倒计时表述 |
| "魔虚羅是'被打到就适应'" | **支持** | 原作台词"对一切事象的适应" + 挨打即开始解析 |
| "适应完就赢（无敌）" | **不成立** | 它被打死过两次（涩谷被宿儺、新宿被五条茈）；适应是**按事象逐项**的 |
| "魔虚羅不可被击杀" | **不成立** | 有实体、会被破坏；弱点是"未见过的高强度一击" |

**一句话**：**它没有血条，但它有"适应进度条"。把它做成"血条"是背叛原作；把它做成"无敌"同样是背叛原作。正确的形态是——一个按攻击类型逐项累积免疫、并且可以被打断/被新型攻击击破的机制怪。**

### 3.5 魔虚羅 游戏化建议

**适合做机制**
- **"适应进度条"取代血条**：每条（或每类）伤害类型各有一条适应进度；同一招反复打 → 进度涨 → 满了就免疫。
- **视觉=机制**：头顶法阵随进度**旋转**，完成时"ガコンッ"音效 + 定格特写。这是**原作自带的最好的 UI 提示**。
- **破解手段明确**：换伤害类型 / 用未使用过的高强度一击 / 在适应完成前爆发。玩家能学会，也符合原作。
- **机制怪而非数值怪**：适合做成"解谜式 BOSS"。

**千万别做**
- ❌ **别只做一条大血条**（丢掉了原作全部特色）。
- ❌ **别做"免疫一切"**（原作明确它会被不懂的攻击/高强度一击打死 —— 做成全免疫就是粪怪，见 §6）。
- ❌ **别做"适应永久且不可逆"**（原作里它是会被破坏的；且玩家必须有出路）。
- ❌ 别让适应速度**只由时间决定**（原作是"挨打加速解析"），否则玩家只能站着等 —— 要做成"**打它=喂招，但打得快=在它适应前打掉**"的张力。

### 5.4 对游戏平衡的直接启示

## 6. 游戏化的取舍建议

### 6.1 ✅ 适合做成机制（原作有明确规则、玩家能学会）

| 原作设定 | 为什么适合 | 建议形态 |
|---|---|---|
| **黑闪** | 判定清晰（误差≤0.000001s）、收益明确（×2.5 + zone）、原作就是"技术"的象征 | 3 帧精准判定 → 伤害 ×2.5 + 10s zone。**可练、不随机** |
| **无下限的"距离减速"** | 视觉直观、有明确破解标签 | 半径减速场 + 展延/空间斩/必中 三类穿透 |
| **蒼 / 赫 的吸斥二择** | 天然一对互补技能 | 拉近连段 vs 击退破防，各有代价 |
| **领域展延** | 原作自带的"破解手段" | 免疫术式/必中，但**只能肉搏**的形态切换 |
| **开放领域 vs 封闭领域** | 结构性的攻防关系，非常适合关卡 | **从外部打破对方领域**做成关卡目标 |
| **魔虚羅的适应（逐类型累积）** | 原作最独一无二的机制 | **适应条 ≫ 血条**（见 §3.5） |
| **反转术式** | 明确代价（消耗、他人效率低） | 咒力换血、施术时动作受限 |
| **無量空処的 0.2 秒** | 原作的"技术上限"时刻 | 可主动压缩时长换取冷却/误伤优势 |
| **开（フーガ）的使用条件** | 有前置条件，天然是"处决技" | 仅对"已被解/捌削减到阈值以下"的目标可用 |
| **式神能力可单独抽出**（満象的水） | 极好的变招资源 | BOSS 可变招，不必每次召完整式神 |

### 6.2 ❌ 千万别做成机制（会变成玩家讨厌的"粪怪"）

| 危险设定 | 为什么是粪怪 | 替代方案 |
|---|---|---|
| ❌ **无下限 = 完全无敌 / 免疫一切** | 玩家没有解法 = 不是打游戏是看动画。原作本身就给了三种破解法 | 做成**有标签克制的减速场**，并**把破解手段明示给玩家** |
| ❌ **无量空处 = 命中即死** | 原作效果是"什么都不能做"，不是"死"。秒杀型必中会让玩家觉得被耍 | **冻结/行动不能 N 秒**，期间可被打；给"领域外壳可被外部打破"的解法 |
| ❌ **魔虚羅 = 一条大血条** | 完全丢掉原作特色（它没有血条概念，见 §3.4） | 适应进度条 + 类型切换 |
| ❌ **魔虚羅 = 适应完就无敌** | 原作里它被打死过两次；无敌即无解 = 粪怪 | 适应**按类型**累积，且**未见过的高强度一击可击破**；适应要有**可打断窗口** |
| ❌ **黑闪 = 随机触发** | 原作明确"没人能稳定打出"，是**技术**的象征；随机化会让玩家觉得赢得不靠操作 | 固定判定窗口，靠技术；可加软保底降低挫败 |
| ❌ **世界斩 = 可反复使用的常规技能** | 它是一次性、学会了就改变战力平衡的"决胜技" | **仅剧情演出使用**，或作为最终阶段的一次性机制 |
| ❌ **六眼 = 自动闪避 / 透视一切** | 剥夺玩家操作与探索 | 只给**效率与信息提示**（消耗↓、预警 UI） |
| ❌ **宿儺的被动再生速度过高** | 玩家打出的伤害被吃掉 = 挫败 | 再生**与他的输出共用资源**（打得越凶、回得越慢），让玩家能感知到压制效果 |
| ❌ **领域熔断后立刻恢复** | 领域战失利必须要有代价，否则博弈消失 | 熔断期间禁用领域，并**明确显示倒计时** |
| ❌ **把"指 N 本分"当数值单位** | 原作里这是**他人的粗略估算**，不是精确单位（见 §2.7） | 想用就用，但要自己定义换算，别声称是官方设定 |

## 9. 一页速览：给开发的 12 条硬结论

1. **五条的无敌是三件套**：六眼（效率/识别）＋无下限（免疫）＋反转术式（修脑）。缺一件不成立。
2. **无下限不是护盾，是"距离无限化"**；破解法有三种：领域展延、开放领域外破、空间斩。
3. **蒼=吸引、赫=斥力（威力2倍、城市受限）、茈=两者相撞的假想质量**；茈是复合术式，200% 需要完全咏唱 + 外援。
4. **无量空处是"什么都不能做"，不是"死"**；0.2 秒是原作给出的技术上限范例。
5. **黑闪是现象不是技能**：误差 ≤0.000001 秒、威力 2.5 乗、命中后进入 zone。五条此战打出四度。
6. **宿儺的御厨子 = 斩击（解/捌）+ 炎（開/竈）**；解=通常斩击、捌=按对象强度自动调整、開=火焰箭（有前置条件，五条战未用）。
7. **伏魔御厨子是开放型领域**：不封闭、半径约 200m、可从外部打碎对手的封闭领域 —— 这是它赢下领域战的结构性原因。
8. **世界斩 = 把「解」的对象从人扩展到空间/世界**，因此绕过无下限；它是**以魔虚羅的适应为范本学来的**，不是固有技。
9. **魔虚羅没有血条，但有"适应进度条"**：挨打即开始解析、法阵每转一次推进、适应完成即可攻击到五条。**它会被打死**（涩谷被宿儺、新宿被五条茈），所以既不能做成血条怪，也不能做成无敌怪。
10. **"摩虎羅"就是"魔虚羅"**；五条战里宿儺另一只真正登场的式神是**嵌合獣「顎吐」**；"貫穢"未找到，正确名是**貫牛**。
11. **五条战 223–236 话、日期 2018/12/24、地点新宿**；五条被世界斩一刀两断；之后依次是鹿紫雲一 → 虎杖+日車 → 乙骨 → 真希 → 虎杖黑闪 → 乙骨（261 话入五条遗体）。
12. **平衡目标应是非对称对等**：双方各自握有"对方答不出的问题"，而不是数值相等。
