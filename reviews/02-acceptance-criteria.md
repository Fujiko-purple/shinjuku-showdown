# 验收标准（Lead 定，最终挑刺以本文件为准）

> 用户原话："要求检查每一部分，眼光要挑剔，要用找麻烦的方式找问题，没有什么是完美的，没有什么是无可挑剔的。"
> "不能觉得这样子差不多可以了，就结束，敷衍掉。"
> "交付前还要再从头全部检查截图找问题。要自己实际游玩体验，站在玩家的视角游玩一遍，骂找问题。"

所以本文件不是"通过线"，而是"最低要求"。**达到这些不等于做好，达不到就一定不合格。**

## 一、视觉验收（每条必须有截图证据）

| # | 项目 | 合格线 | 基线状态 |
|---|---|---|---|
| V1 | **角色屏幕占比** | 战斗中 ≥ 20%，理想 30-45% | ❌ 约 7% |
| V2 | **角色可辨识度** | 不看 HUD 也能一眼分出谁是五条悟、谁是宿傩 | ❌ 两个方块人 |
| V3 | **角色剪影** | 强光/特效命中时仍能看清动作轮廓 | ❌ 糊成白团 |
| V4 | **接触阴影** | 角色有落影，不"飘"在地上 | ❌ 无 |
| V5 | **相机遮挡** | 镜头与角色之间有大几何体时自动处理，绝不出现柱子糊脸 | ❌ 开场就有一根黑柱挡死 |
| V6 | **相机不丢角色** | 任何技能/领域/拉锯状态下双方都在画面内 | ❌ 放「赫」时角色跑出视野 |
| V7 | **技能形体** | 每个术式（苍/赫/茈/黑闪/领域）有可辨识形体与运动方向 | ❌ 只有一团全屏白光 |
| V8 | **不过曝** | 任何一帧的高光占比 < 25%，特效不淹没角色与 HUD | ❌ 「赫」右侧 2/3 屏冲爆 |
| V9 | **场景可辨识** | 一眼认出"这是新宿夜晚的十字路口" | ❌ 乱摆的白色盒子 + 矛盾斑马线 |
| V10 | **场景逻辑** | 斑马线朝向正确、建筑沿街成排、杂物位置合理不穿模 | ❌ 斑马线左竖右横还有斜穿的 |
| V11 | **画面层次** | 有暗部/中间调/亮部，雾不糊死远景，有霓虹冷暖对比 | ❌ 一片灰蓝发闷 |
| V12 | **HUD 可读** | 血条/领域/冷却一眼看懂，文字不糊 | ❌ 血条黑底黑条，看不清 |
| V13 | **HUD 不挡视野** | 战斗主视野区无遮挡，大字不糊在角色身上 | ❌ 「黑闪」大字糊脸 |
| V14 | **HUD 无死控件** | 每个显示的元素都在真实变化 | ❌ 计时器永远 00:00 |
| V15 | **HUD 无冗余** | 战斗中不出现与战斗无关的常驻控件 | ❌ 音量滑块常驻右下 |

## 二、玩法 / 手感验收（必须实际玩过）

| # | 项目 | 合格线 |
|---|---|---|
| G1 | **输入响应** | 按键到动作无可感延迟；连段窗口手感正确 |
| G2 | **一局节奏** | 一局时长合理（目标 90-180 秒），不拖沓也不瞬秒 |
| G3 | **有来有回** | AI 会反击、会格挡、会给压力，但不是无脑压制 |
| G4 | **反馈可读** | 命中/受击/格挡/黑闪的反馈能被玩家感知（顿帧、音效、视觉） |
| G5 | **死亡与结算** | 一方死亡后正确进入结算，结算数据准确 |
| G6 | **重开干净** | 结算后重开/返回标题无残留状态、无报错 |
| G7 | **暂停可用** | 暂停/继续/重开/返回标题都正常，暂停时游戏真的停 |
| G8 | **无卡死** | 完整打一局不出现卡死、掉帧尖峰、状态机卡住 |

## 三、性能验收

| 场景 | 合格线 |
|---|---|
| 桌面 1600x900 | 平均 ≥ 90 FPS，1% low ≥ 55 FPS |
| 手机 390x844（DPR 限制后） | 平均 ≥ 30 FPS |
| draw calls | 桌面 ≤ 250，手机 ≤ 120 |
| 三角面 | 桌面 ≤ 250k，手机 ≤ 120k |
| 首屏体积 | 单文件版不变；站点版 ≤ 2.5 MB（不含按需加载的音频） |

## 四、移动端验收

| # | 项目 | 合格线 |
|---|---|---|
| M1 | 触屏可完整游玩 | 移动 + 全部技能 + 暂停 都能用手指操作 |
| M2 | 多点触控 | 边移动边放技能不冲突 |
| M3 | 布局不重叠 | 摇杆/按钮/HUD 互不重叠，且不挡战斗视野 |
| M4 | 竖屏与横屏 | 两种朝向都能玩；竖屏有横屏提示 |
| M5 | 分辨率控制 | 手机上 `window.__PR_MAX` 生效，不会按 DPR=3 硬渲 |

## 六、交付物

1. `dist/新宿决战.html` —— 单文件，双击即开，功能完整
2. `dist/site/` —— 可静态托管的站点目录（含入口 index.html）
3. `新宿决战.html` —— 原始基线文件（**保留不动**，作为重构前后对照）
4. `reviews/` —— 各模块报告 + 最终验收报告 + 截图证据
5. 一键发布脚本（默认 dry-run，用户确认后才真发）

## 七、挑刺纪律

- 交付前必须**重跑全流程**：标题 → 播片 → 战斗 → 技能 → 领域 → 拉锯 → 胜负 → 结算 → 重开，每一步截图。
- 必须**逐张看截图**并写下问题，不许"看起来还行"。
- 必须**站玩家角度骂**：哪里玩起来难受？哪里看不懂？哪里丑？
- 找到的问题要**修到无可挑剔**，或者明确写下"为什么这个不改"。
