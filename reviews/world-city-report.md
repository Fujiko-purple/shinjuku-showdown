## 二、改了什么

### 1. 道路与标线：从「贴图拼」改成「几何体画」
旧版把路口逻辑烧进 50m 的平铺贴图里，于是出现「左边竖、右边横、还有一道斜穿」。
新版**整条路的标线都是一次性算好的几何体**（一次 draw call，任意距离都锐利，永不与路面 z-fighting）：

- 四向斑马线：条纹方向与所横跨道路的车流方向一致（日本式），四条朝向互相垂直、逻辑自洽
- 停止线（按日本靠左行驶：南向车流走 x>0，停止线在北侧）
- 中央双黄线、每侧 3 车道的白色虚线、路缘白实线
- 路面导向箭头（左转道在最外侧）、路口内导流点线
- 人行道上的黄色点字砖（斑马线两端）
- 标线材质用磨损噪点贴图乘法叠加，不再是「刚刷的白漆」

### 2. 街区与建筑：从「随机漂浮盒子」改成「沿街街道峡谷」
- 每个象限 3×3 个街区，**临街立面严格齐平在 x/z = ±18m**，形成连续街墙
- 路口四角是转角楼（同时占两条临街面），街区内部放高层塔楼，越靠路口越高
- **立面几何细节**（Lead 提的 P0）：层间挑檐（每层一道）、空调外机、落水管、凸窗、招牌挑出支架、店门口台阶，全部实例化
- **店铺层**：8×4=32 格店铺图集（暖光橱窗 + 招牌横额 + 遮阳篷 + 内部剪影），换成不重复的店名洗牌袋
- 招牌：竖招牌（袖看板）+ 横招牌 + 楼顶广告牌 + 大型广告屏（4 帧循环 + 扫描线）
- 立面贴图改成着色器按「实例米数」换算 UV，不用再按尺寸分桶 → 建筑只占 3 组 draw call

### 3. 街道设施
路灯（带臂 + 地面光池 + 光晕 + 光柱）、**横式三灯信号灯 + 行人灯（红黄绿周期 30s）**、
护栏、系止柱、自动贩卖机、街边杂物（花坛/立牌/垃圾桶/路锥）、路边停车（含两辆横在路口外的事故车）、
井盖（几何体）、沥青挖补补丁、电线。

### 4. 战损
碎石从「均匀散落一地的深蓝多面体」改成**集中在 14 个撞击堆**里（含路口中心两堆），
颜色改成混凝土灰白，配钢筋（短、斜插）、板块、裂痕贴花、接地阴影。

### 5. 色调与大气
- 沥青底色改成中性冷灰并提亮，人行道浅灰，两者明度拉开
- 天空改成「深蓝天顶 + 地平线城市辉光」，雾色跟着地平线走，远近两层天际线
- 灯光重配：冷调环境 + 微弱月光 + **地表光池**（路灯暖光 + 店铺外溢 + 霓虹洒色 + 路口补光），
  暗底 + 霓虹冷暖对比，不再是灰蓝一片

## 三、修掉的两个硬 bug（都是「必然崩/必然看不见」级别）

1. **`s.dirs` 为空导致 createCity 崩溃**（Lead 报的 P0）
   —— 街区内部塔楼四边都不在临街面上，`dirs` 为空 → `i % 0 = NaN` → `dir` undefined。
   修法：数据侧为空时补四个方向；代码侧加 `if (!dir) continue;` 防御。

2. **实例网格配了 `vertexColors:true` 但几何体没有 color 属性**
   —— three 会定义 `USE_COLOR` 去乘一个未绑定的 `color` 属性（默认 0），
   结果**光池、信号灯灯珠全部渲染成纯黑（加法混合 = 完全看不见）**。
   修法：给几何体补白色顶点色。顺手加了运行时自检（`vcIssues`），
   现在会扫描所有 `vertexColors` 材质与几何体不匹配的情况。

（另外修了：信号灯灯珠朝向偏移加错了轴、灯珠埋在灯头里；楼顶水箱/桅杆/广告牌用
unitBox 时把「底面坐标」当成了「中心坐标」，整批浮空；广告屏朝向算反，屏幕背对路口像浮空的红块。）

## 六·五、湿路反射（Lead 的加分项，已做）

**硬约束怎么满足的：整套反射没有新增任何 draw call / 没有新增任何 pass。**

两块合起来做，都在既有网格与既有材质里完成：

1. **掠射角反光（并入地面/人行道的 Lambert 材质）**
   给沥青与人行道材质挂 `onBeforeCompile`，在 `#include <tonemapping_fragment>` 之前插三行：
   ```glsl
   float wetGraze = 1.0 - abs( dot( normalize( vViewPosition ), normalize( vNormal ) ) );
   float wetSpec  = pow( clamp( wetGraze, 0.0, 1.0 ), 3.2 ) * uWetAmt;
   gl_FragColor.rgb += uWetColor * wetSpec;
   ```
   物理直觉：看路面的角度越掠射（越"平着看"），湿沥青越接近镜面，把城市天光糊在路面上。
   这就是「远处路面发亮、脚底下还是暗沥青」的湿路观感。`uWetColor` 由雾色（城市辉光）乘 2.2
   再拉一点暖色得到，所以反射颜色和地平线是一套色。

2. **霓虹/灯箱/信号灯的反射拖影（并入已有的 light-pools 实例网格）**
   同一个 `InstancedMesh` 里多加约 100 个实例：沿街两侧每 23m 一条
   `sx≈3 / sz≈23` 的强各向异性椭圆（径向光晕贴图被拉成 1:7 就是"拖影"），
   颜色直接取自店铺/霓虹配色表；路口四角再各加一条红绿灯的短拖影（缩放 1.3×7.5）。

**降级路径**：`Quality === "low"` 时 `uWetAmt = 0`（uniform 归零，同一个 program，零开销），
拖影实例的强度系数也乘 0 且步距从 23m 放宽到 46m —— 手机档既不增 draw call 也不增填充率压力。

**实测**：加之前手机档 120 draw calls，加之后 **仍然是 120**；桌面 194 → 192（视角不同带来的浮动）。
反射强度我调过两版：第一版把灯光拖影做得太强，路口出现一个巨大的绿色 X（像激光），已回退到
现在「能看出是湿的、但不会盖住沥青材质」的档位。
