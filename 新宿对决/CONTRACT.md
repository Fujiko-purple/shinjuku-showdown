## M0 的 6 条验收（探针 A1–A6）

1. **A1 启动**：页面无 JS 异常，两个角色都在场，固定帧计数器在走。
2. **A2 确定性**：同一段输入脚本跑两遍，状态哈希必须逐帧一致。
3. **A3 招架有收益**：在招架窗口内按空格 → 零伤害 + 攻击方硬直 ≥0.5s + 防御方咒力 +12；窗口外按 → 照常吃伤害。
4. **A4 距离即资源**：两人相距 >12m 站 3 秒 → 咒力下降；贴身交锋 → 咒力上升。
5. **A5 零伤害解**：随机抽 3 招，每招至少有一种 \`def\` 能打出 0 伤害。
6. **A6 空招惩罚**：出招挥空后有 ≥0.5s 的可用反击窗口（可以完整打出三连段）。
