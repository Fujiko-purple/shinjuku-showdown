## 项目定位（用户已拍板）

- 用原作的**人物 + 术式机制**做的对战游戏，**不做剧情**。
- **单机默认**：选五条悟或宿傩，打 AI。架构从第一天就按"两个角色都能被玩家操作"设计，联机后续接上。
- **类魂战斗**：硬核，但**每一招都有解**（招架 / 闪避 / 格挡 / 位移 / 打断）。
- 建模：继续程序化几何体，但**按网上原作原图核对剪影**。
- 分发：**站点版为主**（Cloudflare Pages），单文件 HTML 只是可选开关。

## 架构铁律（改代码前先看这五条）

1. **逻辑与表现分离**：\`src/sim/\` 只认「帧号 + 输入包」，不碰 three.js / DOM / 音频；\`src/view/\` 只订阅事件画画面。
2. **固定 60Hz 逻辑帧**：逻辑层永远 \`dt = 1/60\`，用累加器把 rAF 的不稳定 dt 攒成整数帧。顿帧/慢镜属于表现层，**不许改逻辑时间轴**。
3. **招式是数据不是代码**：新招 = 在 \`src/data/characters.js\` 加一行，不许新增模块、不许在 sim 里写 if。
4. **每个伤害都必须有零伤害解**：招式表每行必须有 \`def\` 字段，见 \`CONTRACT.md\` 规则 1。
5. **确定性**：sim 只许用 \`core/rng.js\` 的定种子随机；相同输入序列必须得到相同状态哈希（探针 A2 会验）。

## 目录

| 路径 | 作用 |
|---|---|
| \`src/core/\` | 固定帧循环 / 输入包 / 定种子随机 / 事件总线 |
| \`src/data/\` | 招式帧数据表（起手/判定/后摇/伤害/def 标签/连段） |
| \`src/sim/\` | 世界状态、状态机、命中判定、资源（纯逻辑，可 headless 跑） |
| \`src/view/\` | three.js 场景、角色外观、机位、HUD |
| \`src/vendor.three.js\` | three.js r160（构建时单独成文件，一年缓存） |
| \`build/build.mjs\` | 构建：站点版（主） + 单文件版（\`--single\`） |
| \`_tools/probe.mjs\` | CDP 探针：M0 的 A1~A6 验收 |
| \`CONTRACT.md\` | 12 条战斗铁律 + 验收方式 |
