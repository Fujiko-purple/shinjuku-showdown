## 现在能玩到什么（v0.5）

**一款完整的单机对战游戏**：选人（五条悟 / 两面宿傩）→ 打一场 → 结算 → 再战。

- **两个角色都能被玩家操控**，另一边交给 AI（架构从第一天就按"两人对局"设计，联机后续接上）。
- **类魂战斗**：三个防御动词 + 削韧处决 + 黑闪 + 领域 + 魔虚罗，全部围绕"每一招都有解、每个操作都有收益"。
- **不做剧情**：只借用原作的人物与术式机制。

### 五条悟
| 键 | 动作 | 说明 |
|---|---|---|
| J（可三连） | 体术三连 | 第三段削韧高 |

| G | 领域展开「无量空处」 | 领域内敌人行动不能 |

| Shift | 闪避 | 无敌帧 + 位移 |
| V | 黑闪 | 命中帧 ±3 内按下 → ×2.5 + 10 秒 ZONE |

### 两面宿傩（同上手位对应）
解（远程斩）/ 捌（近身连斩）/ 開·竈（火焰箭）/ 突进 / **領域展開「伏魔御厨子」（开放领域：跑到外沿打掉 3 个锚点就能破）**

### 机制
- **距离即资源**：距敌 ≤12m 每秒回 6 咒力，>12m 每秒 −3 —— 结构性修掉"跑图没收益"。
- **削韧 / 架势崩坏 / 处决**：连续命中打崩对手架势，崩坏时按 K 处决（12% 最大血）。
- **领域对拼**：开放领域压碎封闭领域（原作结构性优势）；封闭方可拆锚点翻盘。
- **魔虚罗**：**没有血条**，只有"适应进度条"；挨打会涨适应（满了免疫那一类），适应中可被打断（返 30 咒力），茈一击击破。
- **三档难度**：简单 / 普通 / 困难 —— 只调 AI 的出手间隔、反应延迟与伤害，不改玩家数值。

## 架构铁律

1. **逻辑与表现分离**：\`src/sim/\` 只认「帧号 + 输入包」，不碰 three.js / DOM / 音频。
2. **固定 60Hz 逻辑帧**：用累加器把 rAF 的不稳定 dt 攒成整数帧；顿帧/慢镜属于表现层。
3. **招式是数据**：\`src/data/moves.js\` 一张表，加招 = 加一行。
4. **每个伤害都有零伤害解**：每招都有 \`def\` 字段（招架/闪避/走位）。
5. **确定性**：sim 只用定种子随机；同一输入序列两遍逐帧哈希一致（探针 A2）。

## 已知问题（诚实清单）

1. **平衡只做过 bot 试玩**：会自愈 + 用术式的 bot 能在普通难度 63 秒 KO 对手（掉血 572）；只会平 A 的 bot 会被反杀。人类手感还需要你实测反馈。
2. **魔虚罗的模型是沿用旧工程的简化版**（法轮 + 四角 + 马步），还没按 \`reference/\` 里的原图重做。
3. **联机未开始**（按规划放在 M6）；输入层已经是可序列化的纯数据，具备接入条件。
4. 没有 BGM（只有程序化音效）；没有存档/成就。
5. 场地只有一块（新宿十字路口），没有换场地。
